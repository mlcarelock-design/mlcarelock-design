# Marcie Carelock

Journalist, researcher, and artist in North Little Rock, Arkansas.

I run **Spatial Legacy LLC**, an accountability journalism zine covering Arkansas data center infrastructure, campaign finance, and legislative capture. The rule is simple: receipts first. Checkable facts and people's own words do the work.

I also make children's picture books and visual stories, built the same way — by hand, with care, from real material.

## Current work

- **Spatial Legacy** — accountability journalism zine
- **Princess Lunelle** — a 12-page watercolor picture book
- **Knight Peeps and Jester Scooter** — the third Lunelle book
